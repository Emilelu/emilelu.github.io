○○っす　#13

（BV1xA4jzzEPM，02:54）

起点：敬语判断标准的变化

  • 传统日语敬语严格基于上下级关系。
  • 现代则更重视心理距离——即"亲疏关系"。

二维坐标

親しくない親しい
改まり度・丁寧さ +（高）敬体など：これは本当でございますか／これは本当ですかこれ本当っすか
改まり度・丁寧さ −（低）（保留敬体）常体など：これ本当**？**

「○○っす」的来源与性质

  • 「○○っす」是助动词「です」的派生形式（○○です → ○○っす）。
  • 根底仍是丁寧語意識：
    • 与タメ口划清界限，对前辈/上司使用也不容易显得失礼。
    • 同时砕けた口语音响，能快速拉近心理距离，表达「敬意 + 親密」的微妙平衡。
  • 这种恰到好处的平衡与现代人际关系的理想形态契合，所以被广泛使用。

使用注意

  • 助动词「ます」没有「○○っす」这种形（✗ 行きっす）。
  • 一般情况下女性几乎不使用「○○っす」。
  • 虽受批判，但作为语言适应社会变化而演化的范例，仍被普遍接受。
  • 用时需考虑TPO（场面・对方・场合）。

「よさそうだ」为什么多一个「さ」　#6

（BV1R84y157sY，04:56）

规则回顾：样态「そうだ」接形容词

  • 形容词词干 + そうだ：
    • 忙しい → いそがしそうだ（去掉词尾「い」）
  • 但有两个例外，中间会多出「さ」：
    • よい／いい → よさそうだ
    • ない → なさそうだ

为什么？从"音拍（mora）"看

词去掉词尾后拍数
いそがしいそがし4 拍（足够稳定）
よ / なよ / な仅 1 拍（不稳定）
  • 《大辞林》的接续描述：形容词中词干只有一个音拍的（ない・よい），要用「なさそうだ」「よさそうだ」这种**中间加「さ」**的形式。
  • 最有说服力的解释：一拍词干本身不稳定，加「さ」是对这种不稳定性的增强/补偿。
    • 通俗说：只剩一拍就直接接「そうだ」，容易听错、听不清在说什么，所以需要补足。

有意思的例外：「濃い」

  • 「濃い（こい）」去掉词尾「い」后也只剩一拍「こ」。
  • 但"看起来很浓"标准说法仍是「こそうだ」，不是「こさそうだ」。
    • （说「こさそうだ」日本人也听得懂，但标准说法不加さ。）

复合词也要加「さ」

  • 「申し訳なさそうだ」——「申し訳」是名词 + 形容词「ない」构成的复合 → 加「そうだ」时仍要插入「さ」。

对照：「すぎる」的接法不同

前接词加「すぎる」加「そうだ」
ないなさすぎる（要「さ」）なさそうだ（要「さ」）
よい／いいよすぎる（不要「さ」）よさそうだ（要「さ」）

→ 两者接续规则不同，不要类推。

补：动词否定 + すぎる

  • 标准说法不加「さ」：
    • ✅ 知らなすぎる
    • ❌ 知らなさすぎる
