授受动词难以习得的原因之一　#10

（BV1w2MMzYE6m，02:34）

起点：一句话可以译出三种中文

「泥棒が警察に捕まった」的三种中文译法：

  • 小偷被警察抓住了。
  • 小偷现在在警察手里了。
  • 警察抓住了小偷。

日语一个被动/受事主语句，对应中文有"被/在…里/主动 SVO"三种说法——初学者困惑这种"对应错位"。

关键：日语有一类"受け手立場動詞"

  • 特征：动作的接受者做主语，动作的施事以「に」格出现。
  • 这类动词被称作「受け手立場動詞」（受事立场动词）。
  • 例：捕まる・教わる・見つかる・助かる・預かる・もらう …

もらう 难懂的原因

  • 「もらう」也归入授受动词，但主语总是「接受もら行为」的一方——这一点与「あげる/くれる」不同。
  • 例：
    • 私は李さんに本をもらった。（李给"我"书）
    • お父さんに駅まで迎えに来てもらった。（父亲替"我"来接）
  • 即使不是具体物品而是好意，主语仍是"もら的接受者"：私は君に気遣ってもらっては申し訳ない。

与「教わる」的对比：有没有感激色彩

  • 私は先生に日本語を教わった。 → 事实描写，受事方视点（中性）。
  • 私は先生に日本語を教えてもらった。 → 含「ありがたい/助かった」等感激之情。

中文的对应处理

  • 中文里哪些句式能/不能成立，取决于多个因素：
    • 搭配对象是否抽象（得救/挨打/吃亏/受伤/中招/中毒…）
    • 语义是否负面（"得/挨/吃/受/中"这五个"遭受"义动词有各自的搭配边界）
    • 动作或变化是否突然 vs 阶段性
    • 文体

给译者的提示

  • 不要把「泥棒が警察に捕まった」机械套成"警察抓了小偷"。
  • 根据上下文语义（被动／处置／状态描述）选择最贴近中文语感的形式。

下期悬念

「私は君に気づかってもらっては申し訳ない。」 → 自然的中文怎么译？

命令形的边缘用法　#23

（BV1MnJw6KEGR，03:31）

基本用法

直接要求对方做某行为。前提：听者是能执行该行为的存在，说话人期待其执行。

  • 例：窓を開けろ。

五种边缘用法

用法例含义
欢迎/礼貌称呼いらっしゃいませ（「いらせ給え」的命令形）形上是命令，实为欢迎、礼貌招呼，几乎不强制对方
断念/放弃参与もういい、勝手にしろ不是希望对方去做，而是说话人放弃参与
威嚇/警告/强感情もういっぺん言ってみろ、殴るぞ形是命令，但实质是禁止/警告（言わないで）；用命令形强调愤怒等强烈情感
对无意志事物的强烈愿望雨よ降れ／高校生に見えろ对无法直接控制的事物/结果表达强烈愿望
让步（…にせよ／…にしろ）代表者が誰であれ／どういう形にせよ論文提出／成功するにしろ失敗するにしろ形式不论／结果不论——"哪种都行"

关键

  • 命令形的形态不变，但实际功能随上下文大幅扩张。
  • "强制与否"和"说话人期待什么"才是判断落脚点。

自动词的下位分类：意志 vs 非意志　#28

（BV1kLut6uEYk，01:30）

起点

「走る」「死ぬ」——都是自动词（都不能带目的语）。 但二者不是同类自动词。

自动词的两种类型

类型含义例
機能自動詞（意志性）主体意志性地进行动作走る、帰る、歩く…
非対自動詞（非意志性）主体发生的状态・变化，不由意志决定死ぬ、倒れる、落ちる、壊れる…

与英中的对照

  • 英语 die 通常不说 stop dying 这种进行体；中文"死"对应动词通常也不直接做被动（×被他死了）。
  • 但日语可以：父に死なれた——这是间接受身（说话人因父之死而受困／蒙受损失）。
  • 客に帰られた也不是单纯事实，而是"客人走了，我倒霉了"（间接受身，说话人受影响）。

意志性自动词 + て形：「动作进行中」

  • 佐藤さんが走っている＝佐藤正在跑。
  • 表示动作正在进行。

非意志性自动词 + て形：「结果状态的持续」

  • ビルが倒れている＝大楼已经倒了，并持续保持这种结果状态。
  • 表示变化完成后的状态续续。

→ 同样是「自动词+ている」，意志性 vs 非意志性的区别决定了是"进行"还是"状态续续"。

学习启示

  • 日语自动词不能笼统对待——区分意志性/非意志性，就能解释：
    • 为何「〜ている」有时表"进行"、有时表"结果状态续续"；
    • 为何某些自动词可以接间接受身（迷惑・利益的表达）。

动词分类的本质：五段 vs 一段（#5）

（BV1HP411z7vX，03:33）

教材常见分类法（作者认为非常错误）

  • 不以「る」结尾 → 一类动词（五段）
  • 以「る」结尾，且「る」前假名不在い段・え段 → 一类（五段）
  • 以「る」结尾，且「る」前假名在い段・え段 → 二类（一段）

问题：背离本质，会给记忆带来巨大负担——需要硬记大量"特殊的一类动词"，但它们本来就是普通的一类动词，并不特殊。

本质：日语动词活用的变迁是「二段活用 → 一段化」

  • 上二段 → 现代上一段
  • 下二段 → 现代下一段
  • 正因为有这段变迁，现代日语的一段动词（二类）在形态上是有规律可循的，完全不必对「る」结尾的五段动词强行分类。

抓住本质的判断法

  • 变迁会在汉字后留下痕迹：
    • 「落つ」→「落ちる」（つ → ち）
    • 「受く」→「受ける」（く → け）
  • 所以只要去掉末尾的「る」，看紧挨汉字外侧的那个假名：
    • 若是い段音或え段音 → 几乎肯定是一段动词（二类）。

好处

  1. 符合日语本质与历史变迁过程；
  2. 只需记住极有限的几个例外：去掉「る」后只剩一个音（一个汉字）却仍是二类的动词（如「見る」「着る」「寝る」等）。
  3. 与规则不符的只有一个词：「混じる（まじる）」——它是五段动词。

通则

不管学什么知识，抓住本质都是最重要的。
