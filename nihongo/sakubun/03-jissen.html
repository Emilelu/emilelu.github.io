实践1：日记・小说　#22

（BV1VY411C7tu，08:10）

日记 vs 小说

  • 日记写给自己看，小说写给别人看；但外语写作（尤其应试）时差异不大 → 合并讲解。

不知从何下笔时：5W1H 原则

  • いつ・どこ・誰・何・なぜ・どのように
  • 先列出想写的各个部分，再利用日语黏着语的特性，用格助词・接续助词・副助词把它们拼接成完整场景。
  • 例：「今日は雨が降っています」（いつ・何）→「朝までは晴れていましたが、昼から急に降り始めました」→ 描述「誰」（母が…と言っていた）→ 描述「なぜ」（なぜなら傘をさしても…濡れるから）

让表达不"幼稚"的三点

  1. 句末不要全是「ました」 → 让句尾产生变化：
    • 用「た」交代是过去发生的，之后用现在时描写；
    • 可用名词结句（修辞）；
    • 用助动词等避免过多「〜ました／〜でした」。
  2. 避免反复出现人称代词（尤其「私は」）
    • 先用定语修饰"我"，后面直接描述事情经过即可。
  3. 接续词・接续助词不要过频
    • 依靠故事情节的变化自然产生句子之间的关系。

让表达"高级"（修辞）

场景手法例
情景描写拟人使表达显得高级
心理描写避免直接描述❌「うれしくて泣きそうになった」
✅「硬直した体が緩み、温かい血が全身を巡り、目の端に熱いものを感じた」
悲伤时：「暗い水底に引きずり込まれるように息苦しい」
人物描写抓住动作・气氛・台词「足を机に上げて座った」→ 表现桀骜不驯；外貌 + 给人的气氛

实践2：随笔　#23

（BV1z64y1P7aQ，06:36）

随笔是什么

  • 基于自己的体验获得的知识 + 自己的感想感悟 → 散文。
  • 由两部分构成：①自己的体验 ②自己的感想（有机结合）。
  • 与论文的区别：不需要严密的论证过程。

写随笔的注意点

  1. 必须基于自己的经验；
  2. 是给别人看的文章（不是日记）；
  3. 不能只写肤浅感想，要有自己独立的思考。

抓住三点

  • 主题与素材来自周边已经发生的事情；
  • 写出具体事实 + 感想；
  • 与生硬书面语不同，随笔可以写得简单些（可用偏口语的表达）。

出类拔萃的三点

  1. 内容与读者产生共鸣；
  2. 写身边不那么常见的事（过于常见没意思）；
  3. 有自己独特的视点与思考。

范文《言葉の重み》（语言的分量）结构

部分内容
起因日常看到"杀人事件不断增加"
作者的思考有些人不说真实想法一直忍耐 → 像气球膨胀 → 终有一天破裂（引发事件）
追问为什么没人发现？→ 因为先入観（成见）
正反论证语言对人的负面影响 vs 仅仅一句话让人非常高兴
结论一句话可能温暖人心也可能伤人 → 要重新审视自己所说的话
进一步除关注身边哭泣的人，也要关注看起来活泼的人（外表无恙，内心可能有阴暗面）
结尾"没有犯罪的世界"是否可能？答案是否定的，但只要相信并脚踏实地前行，终会到来

实践3：读后感　#24

（BV1fm4y1Z7LB，09:45）

四大部分（感想是核心）

  1. 开端：为什么选择写这本书 + 读之前自己的状态
  2. 故事梗概：主要内容总结
  3. 感想：整篇最重要的核心
  4. 总结：学到了什么 + 读后自己有哪些改变

经典句式（可直接套用）

开端

  • 用「しかし」将自己与书中主人公对比
  • 「〜から、この本に興味を持った」
  • 「私がこの本を選んだ理由は〜」
  • 「〜一冊の本が目に留まった」＋ 介绍封面（学生服の男子がサッカーボールに足を乗せている爽やかなイラストが表紙に描かれた）

梗概

  • 用实践1 的 5W1H 方法
  • 「〜少しずつ変わっていく物語だ」＋ 介绍题材 ＋「〜場面もありました」

感想（核心）

  1. 「今でも忘れられないのは〜（场景）」＋ 感想
  2. 「〜の場面が印象に残った。もし私なら〜（与主人公行动对比）」
  3. 「最も心を動かされたのは〜（一句话/一个场景）」
  4. 「この本を読む前は〜だったが、〜を読んで、今後は〜していきたい」
  5. 「一番好きな登場人物は〜。理由は〜」（也可写"最讨厌的是谁＋理由"）

总结

  • 「私はこの作品を読むまで、〜の重要さについて考えたこともありませんでした。しかし今は違います。〜ことを学びました。」
  • 「この本は私に〜の大切さを教えてくれました。主人公が〜したことをきっかけに、今まで気にも止めなかったことに目が向くようになりました。その結果〜。これからの生活の中でこの本から学んだことを生かして行動していきたいと思います。」
  • 「この本を通して作者は〜を伝えたいのだと感じます」／「〜ことに気づきました」／「このことを胸に深く刻み過ごしていきたいです」
  • 「〜のように強い意志とその先にあるものを目指して一歩ずつ進んでいきたいと思った」

四种创作类型（不必死守"开端→梗概→感想→结尾"）

类型结构
① 感想展开型（最常见・应试推荐）先给出最深刻的感想 → 具体展开（结合自己生活）→ 升华（与社会问题对比）→ 结论
② 问答型首段抛出问题 → 通过故事梗概论述 → 末段解答（解答即感想＋总结）
③ Before-After 对照型读前的想法/行为 vs 读后的想法/行为交叉对比 → 得出结论
④ 高级型先写一个与书无关的话题 → 展开 → 最后回到书中内容（制造意外性）。应试一般不用

实践4：说明文　#25

（BV1iG4y1k7RP，04:47）

说明文是什么

把某个人／某件事／某个东西原原本本地向不了解的人阐述。

  • 两个要件：①准确性 ②易懂性
  • 必须写成书面语（口语/书面语的区别见进阶部分）。

必须避免的三类表达

类别说明
授受表达授受动词这一类
被害表达用被动态表示受害
主观表达最容易忽视、最容易搞错

例题改造

❌ 前回の野外実験は台風に来られて装置が破損してしまった。しかし今回は一週間も晴天が続いてくれたおかげで実験に成功した。

问题逐一对应：

表达问题
台風に来られて被害（被动受害）
破損してしまった遗憾・后悔语气
一週間も强调"主观上觉得时间长"
続いてくれたおかげで"多亏了……"，主观色彩浓重

✅ 改法：用**形式名词「ため」**等客观表达原因、直接陈述事实、去掉「も」「くれる」「おかげで」。

核心能力：判断一个语法是"客观"还是"主观"

  • 学语法不能只记词性・接续・含义，还要掌握它是在客观陈述事实，还是带有说话人的主观色彩。

  • 主观 → 客观的对应例：

    主观→ 客观
    ことだしため
    くせにが
    が早いか（相应的客观表达）

  • 这类"看似同义、实则一主观一客观"的对应关系非常多。

  • 分不清这一点，写说明文・议论文时就会处处出错。

实践6：意见文（建议书）　#27

（BV1SW4y1J7eJ，04:07）

意见文 vs 小论文

重点
论文（小论文）论述的过程
意见文对某个问题提出自己的意见・主张・想法

最简单的三部分

  1. 对事实提出自己的意见（主张）
  2. 理由与根据
  3. 总结

例（是否增设爱心座）：

  • 主张：没有必要增设爱心座
  • 理由：乘车的每个人互相为对方考虑即可
  • 根据：德国没有爱心座，人们会按需让座／被让座
  • 总结：再次陈述主张

最难也是核心：写出"支持或反对的理由"

  • 例："穿校服是好还是不好" → 赞成有 7 种理由，反对也有 7 种理由。
  • 找到合适的理由，是写意见文最重要的环节。

技巧

  • 多个理由：用接续助词或接续词连接（补充理由时常用接续词）。
  • 字数不够／想更丰满：加入自己或别人身上真实发生的事情。
    • 例：有校服就不用每天早上急急忙忙想穿什么。
  • 进阶做法：写完自己的主张后，在总结前先陈述并理解相反的观点，再说出自己真正的意见 → 使文章更理性、内容更丰富。

实践5：小论文　#26

（BV1k24y1d7VR，16:35）

作文 vs 小论文

作文小论文
内容对自己经历的描述 + 主观感想提出立场 + 论述赞成/反对的理由
主体故事描写论述
要求—有说服力、站在客观视点

论文四基础部分

① 作者的主张 → ② 主张的根据 → ③ 具体的事例 → ④ 结论 （例：日本应大量接受外国劳动者 → 理由 → 具体事例 → 结论）

四种论述方法

方法说明例
归纳法由多个事实得出结论傍晚烟飘向东→次晨下雨（连续数日如此）→ 此地傍晚刮西风就会下雨
演绎法由一般性原理推出结论人固有离别 → 我们也总会与父母分别
三段论法大前提 + 小前提 → 结论人是动物／我是人／我是动物
辩证法正反对立观点组合 → 更高层次的结论地球环境危机 + 科技本为幸福而生 → 善用科技可实现人与自然共生

开头的五种写法

  1. 直接下定义
  2. 写为什么要写这篇论文的原因
  3. 引用格言
  4. 向读者设问
  5. 开门见山讲一件不寻常的事（如"熊闯入民宅引发骚动"）抓住注意

开始论述时避免主观表达，尽量客观描述（如"我认为训练是必要的"→ 用自发态等方式改为客观表达）。

结尾的四种方式

  1. 与开头呼应
  2. 呼吁的方式（〜べきだ 等）
  3. 总结形式（上述をまとめると〜）
  4. 展望未来的研究课题（残された課題として〜）

论文常用表达模板

功能表达
提出论点本論文では〜がどのように形成されてきたかについて考察する
必要条件〜必要がある；更强烈：〜なければならない
指出先行研究的问题点〜についての研究は極めて少ない／〜についての検討は十分に行われているとは言えない／〜についての研究はほとんどなされていない／不明な点が多い
研究目的本研究の目的は〜を明らかにすることである／本研究は〜を解明するためである
下定义〜とは〜を指す／〜とは〜のことである
主动：〜を〜と定義する（某人定义时用主动，如「佐藤は〜と定義している」）
被动：〜は〜と定義される（不特定多数认可的定义）
分类〜は〜に分類される／分けられる；粗分 大別される → 细分 さらに〜に分類される；依据用 〜によって／〜のことで
图表〜の推移を図1に示す／図1は〜を示している／表1に〜を示す／表1は〜を示したものである
数值不足：〜未満；超出：〜を超える；占比：〜を占める
约数（论文用）：約・ほぼ・おおよそ・程度・前後（「ぐらい／ばかり」太口语，不用）
不足：弱（じゃく）／近く（ちかく）；超过：強（きょう）／余（あまり）
变化大幅な上昇が見られる／主动句：上昇を見せている
无变化：変化が見られない；长期不变：表示"持续不变"的表达
对比〜に対して（基础）／〜より多かった（前者更多）／〜よりも〜のほうが〜（后者更…）
排序第三位は〜で、以下〜の順になっている
得出结论これより〜がわかる／このことから〜がわかる；更书面：〜は明らかである
原因〜のは〜ためである／〜の原因として〜があげられる／〜背景には〜がある／〜は〜に起因している
预测〜と予測される／予想される；某人的预测：〜は〜と予想している；大众：予想されている
※予測比予想基于更精确的证据
引用〜と述べている／〜と言われている／〜とされている

列举

  • 一种列举形式后面必须跟名词谓语句；另一种形式后可接任意形式的句子。
  • 顺序词：まず／次に／また／さらに／終わりに／他にも
    • 两个事物：まず・また
    • 三个：まず・また・さらに
    • 四个及以上：按相应顺序
    • 他にも：列举其他情况

同意 / 反对

立场表达
同意〜の見解に賛成である／〜に異論はない
间接：〜が〜と述べていることが注目される
反对〜の見解に異論がある／〜には同意できない／〜には疑問がある
间接：〜は〜と述べているが、どうだろうか
常用"先暂且认可后转折"：確かに〜。しかし〜

实践7：报告（レポート）　#28

（BV1124y1Q78j，06:03）

报告 vs 论文

论文报告
目的论证某事物・现象总结已经得到的结论或知识
  • 分类：一般性报告（含序论・本论・结论，与论文/意见文类似）／调查・实验报告

调查・实验报告的四部分

目的 → 方法 → 结果 → 对结果的考察与展望

常用句式

部分表达
开头（方法概述）〜に実施したアンケート調査の結果を中心に、調査対象の〜について報告する
结果〜と尋ねたところ、〜（前引问卷问题，后详述结果：〜％の人が〜と回答した）
自己的看法〜と言える
结尾（考察与展望）今後も〜に関する〜調査を定期的に実施することで、対象者の〜の把握に努め、〜が改善されるよう取り組んでいきたい

范文结构：「割愛（かつあい）」词义变迁的问卷调查

段内容
1 目的词典中该词的意思 → 用「ところが」转折，指出现代使用中出现新状况（单纯当作"省略"来用）
2 方法在网上把 A、B 两个例句做成问卷，对 600 人调查
3 结果传统上 B 正确、A 奇怪，但这样回答的人只占约 25%；49% 认为（原为误用的）A 才是现代主流
4 考察・展望原本"割愛"只用于非常重要的事，现代则未必——即使是不重要的事也用它表示"省略"

→ 其他学科也按目的・方法・结果・考察这四部分来写。

实践9：广告语（キャッチコピー）　#30

（BV1jG4y1M7Pc，08:21）

随着跨境电商发展，写广告语逐渐成为日语写作中必不可少的训练环节。

首要原则：不要"又长又完整"

  • 语法正确但太长・太完整・太繁琐的句子不适合做广告语。
  • 例：改为「この性能で、この価格。」（这么强的性能、这么便宜的价格）
    • 简洁、有节奏感，并使用了名词结句的修辞（进阶5）。
  • 夸张表达也适合：「この性能でこの価格、嘘でしょ？」

广告语 20+ 个诀窍

类别做法 / 例
明确目的如旅游广告就围绕"旅游"
具体说明好处不说「体にいい」，而说「脂肪の吸収を抑える」
简洁・有节奏感如泡面广告，短促有力
明确对象「〜でお悩みのあなたへ」
主动提供信息「〜をお教えします」
小故事「一晩で100点上げた」（让人想点进去看方法）
数值化「リピート率 98.5%」
刺激欲望与季节相衬的衣服
抒发情感「運命を変える一品との出会い」

实践8：书信・邮件　#29

（BV1JG4y1A7Zv，07:32）

书信的基础格式见基础第10课。

一、先定"语体"：和语 vs 汉语

同样内容，日语有两种风格：

语体感觉例
和语平易近人お知らせします
汉语生硬・正式ご通知申し上げます
  • 第一步：根据写的内容与对象，决定以和语为主还是以汉语词汇为主。

二、头语与结语（頭語・結語）

  • 一般成对出现（如「拝啓」→「敬具」）。
  • 按场合选择：一般场合／礼貌场合／省略寒暄的场合／有急事的场合／回信的场合／就同一件事再次写信的场合。
  • 现代（尤其电子邮件）也常不写头语结语。

三、寒暄语（時候の挨拶）

  • 难记，实际写信时通常上网查特定的寒暄语；考试记典型常用的即可。
  • Word 可插入：「插入」选项卡 →「日语问候语」→ 按月份选择时令寒暄；开头语・结语也能选。
  • 并非任何场合都要寒暄：
    • 道歉信・慰问信一般不用寒暄语；
    • 商务场合必须有。

四、结尾寒暄的六种

  1. 祝福对方健康幸福
  2. 希望对方事业有更大发展
  3. 期待今后仍有联系
  4. 总结前文
  5. 希望对方帮忙传达某事
  6. 希望得到对方回信

五、商务信件的结构要点

  1. 时令寒暄之后 → 祝愿对方健康或生意兴隆
    • ⚠️ 这一部分一般用肯定句，不用疑问句（要"确信"对方生意兴隆/身体健康）。
  2. 接着对对方表示感谢（いつもお世話になっております 等）。
  3. 开始写正文时一般要加起语（「さて」等）。
  4. 结尾不要忘了结尾寒暄和头语・结语。

六、敬语的三个易错点

易错点说明 / 例
① 「ござる」与「いらっしゃる」说对方的事不用「ござる」，要用「いらっしゃる」；
只有说自己这边的事才用「ござる」。
❌ 田中さんはどちらからござる？ → ✅ いらっしゃる
② 双重敬语特殊尊他语 + 尊敬助动词叠加 → 一般视为错误，要避免
③ 敬语过度为表敬意而过分使用，要避免（如"正在交往"直接写即可）

七、忌讳词语

  • 避免不吉利的表达：
    • ❌「失敗しないように頑張って」
    • ✅「うまくいくように応援しています」

实践10：提高写作水平的三个要领（全套教程最终课）　#31

（BV1mG4y1M7vf，05:38）

课程回顾

阶段内容
基础 1–10从语法与用词层面梳理写作中最容易犯的基础错误
进阶 11–20在基础上扩展，教如何写出更地道的日语句子
实践 21–31按题材分别讲解并练习写作方法

写作对母语者也不容易，用外语写作更是难上加难——想要写好，可能需要十年甚至二三十年的努力。

要领一：学会思考（思考能力）

以"一张画着木材的图片"为例：

  1. 先描述场景：「空き地に材木が置いてある」→ 太单调。
  2. 加修饰成分使其具体生动：「少し傾いて、形も大きさも違う材木が置いてある」。
  3. 但只描述不能成为作文 → 需要思考扩展：
    • 形状大小不同的木材组合得好就能盖房子；
    • 更抽象一步：人也一样，每个人不同，应构建能容纳形形色色之人的社会；
    • 继续扩展：不应建造所有人都一样的社会，而要注重人与人之间的差异；
    • 最后：想要更好的社会，我们需要怎么做。 → 从一张木材图片扩展到人类与社会，这就是写作中必不可少的思考能力。

要领二：在阅读中提高（不能"读完就完")

  • 不能像做阅读理解那样"题目做对就行"——那太可惜了。
  • 要珍惜每一篇日语母语者写的文章，从两方面入手：
    1. 文章的构成：如果使用这篇文章的构成，我要怎样完成自己的文章？
    2. 其中使用的表达：
      • 背诵将来可能用到的日语句子；
      • 必要时抄写好的表达，在以后写作中用进去。

要领三：练习"替换说法"（言い換え）

  • 方法：在日本雅虎等搜索引擎输入「某词 + 言い換え」。
  • 搜索结果中的表格非常有用——根据一个词的不同侧面，可以有多种替换说法。
  • 效果：既提高词汇量，又使表达更生动多彩。
  • 积累需要常年累月的时间。
