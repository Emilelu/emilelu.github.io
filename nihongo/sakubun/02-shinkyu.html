接续词

  • それで（因此）和そこで不同：そこで是在某种状况下做什么，所以后面接有意志的行为
  • そして起补充作用，前后主语一致；すると（于是）前后主语一般不同
  • おまけに强调前面的句子，后面起补充作用
  • また表累加、并列；または表或者
  • もしくは比あるいは更正式
  • しかし＝单纯逆接（否定前项）；ただし和もっとも＝补充的逆接（不否定前项，借前项引出补充内容）
  • つまり：换句话说、总之（＝要するに）；すなわち比要する更正式，只能表示"换句话说"
  • いわば：比喻句式——XXは いわば XXのような XX ものだ
  • さて比ところで更正式，用于转换话题

指示词

指示词可分为现场指示和文脉指示。

修辞

直喩／隠喩／換喩（惯用语中非常常用）／擬人／誇張／体言止め（散文、广告语中常用）／倒置／反復／対句／声喩／提喩（通过XX代指XX，比较高级的修辞手段）／同語反復（起强调作用）／共感覚表現（通感：比如用对声音的感觉修饰味道）

  • 修辞手法很难成为正式表达：撰写论文、报告等正式文章时一般少用或不用，主要出现在小说、故事、散文等文体中。

视点

  1. 日语视点更倾向站在第一人称：说话人、说话人的学校、公司、组织，以这些为基准描述事态
  2. 更倾向于固定：确定整个故事以谁展开后，自始至终站在这个人或事物上描写，一般不随意切换视角

动词

暂略

ヴォイス

  • 有时会有一个独立的词来使视点保持在第一人称
  • 动作的主体不确定时可以省略；若需强调动作主体，可在被动句中用によって
  • 为使视点统一，有时会将自动词变成相应的使役态来表达
  • 有时てくる、ていく、授受动词缺失的话，句子会变得难以理解甚至错误
  • 客观陈述某个事态时，不能使用授受动词
  • 差し上げる在商家对客人的场景中，有强调"我给你恩惠"之意，对客人失礼，不能使用 → 用いたす即可

独立词误用

误 ✗正 ○说明
愛人恋人情人≠爱人
短処短所
学分単位
出席を呼ぶ出席を取る点名
仕事が積もる仕事がたまる积攒了很多工作
  • 穿裙子、裤子、鞋子等下半身的，一般不用着る，而用はく
  • 喜ばしい是站在第三人称角度陈述的；表达自己高兴要用嬉しい

附属词误用

  • 朝着某情况不断发展、越来越怎么样 → 用一方だ的形式，「だ」不能省略，否则表达不出相应含义
  • 薬を飲むのは必ず役立つ。✗ → 薬を飲むと、きっと効く。○
  • 不自然：平日と同じ時に起きるのが難しいということは……
  • 自然：平日と同じ時間に起きられないということは……（直接使用可能态的否定）
  • のだから
  • をめぐって
  • 表达强烈的批判语气：动词可能态过去式＋ものではない
  • て表示轻微的因果关系，后面一般不伴随意志相关表达；有强烈意志用から表示明确因果关系
  • 确定的逆接关系不能用でも，而是用なのに
  • ば连接的后项主句，一般是积极意义或客观陈述；消极的话要用たら

进阶3：句子 → 段落　#14

（BV1SS4y1b7mV，02:53）

为什么要分段

  • 一篇文章如果只有一个段落，会非常难读（文章一般由多个不同主题组成，全塞进一段会晦涩）。
  • 一般做法：一个段落包含一个主要主题。
  • 这一点与汉语写作规则相同。

每个段落要有"中心句"

  • 段落围绕一个中心句展开，其余句子是支持句。
  • 中心句通常出现在段落开头或结尾（也有在中间的情况）。

形式段落 vs 意义段落

概念说明
形式段落形式上空一格分出来的段落
意义段落虽由多个形式段落组成，但意义上是一个整体
  • 意义段落可能少于形式段落。
  • 例：第1段＝序论（提出研究主题）／第2、3段＝本论（从两个侧面论述）／第4段＝结论 → 意义段落只有 3 段，不是 4 段。

进阶4：段落 → 文章（文章构成法）　#15

（BV1zR4y1w76A，05:40）

文章最基本：三部分（序论・本论・结论）

  • 高考写三段也可以。
  • 文章分两大类：文学类（描写故事）与议论文（阐明观点）。

三段构成

类型结构
文学类序破急（日本古典文艺术语）：序＝开端／破＝进展／急＝终结
议论文提出观点 → 论证 → 结论

四段构成

类型结构
文学类起承转结：起＝开端／承＝发展／转＝变化・转机（故事转向另一方向）／结＝结局
若故事无明显变化：开端 → 展开 → 详细描写最高潮 → 结局
议论文在论点与论证之间插入"说话"部分＝举出实例，证明"这个论证有必要"
  • 起承转结源自中国古诗（第三句一般都有变化）。
  • 高考若能写四段，比三段更丰满 → 有把握建议写四段。

五段构成

类型结构
文学类在最高潮后插入「破局」——发现解决关键矛盾的钥匙，将故事推向结束
议论文（写法1）论点 → 论证 → 提出相反结论 → 反证（间接证明自己正确）→ 结论
议论文（写法2）论证之后加「列序」——再举例子证明结论正确
  • 也可在"给出论点时"先论证这个论证有必要，再在论证后给出证明结论的例子。

关键提醒：以上都是"意义段落"，不是"形式段落"

  • 序论本论结论 ≠ 必须写三段；起承转结 ≠ 必须写四段。
  • 某个意义段落篇幅过长时，可以拆成若干个形式段落。

进阶2：用接续助词・接续词连接句子　#13

（BV1oF411T73q，13:59）

概念区分

术语作用例
接续助词连接两个小句天気がいいから散歩しましょう
接续词连接两个独立的句子天気がいい。だから散歩しましょう

接续助词的两个注意点

  1. 区分"假定的逆接"与"确定的逆接" → 使用的接续助词不同
    • 假定逆接：就算感冒了也去（ても）
    • 确定逆接：已经到秋天了还这么热（のに）
  2. 「たり」在书面语中要连续使用两个以上
    • 口语中只用一个「たり」勉强可以；书面语中被认为不正确 → 后面必须再接「たり」。

接续词一览（按功能）

因果

表达语体/用法
だから／なので偏口语
そのため正式（日本は資源がない。そのため原子力を重視している）
それゆえに更正式
従って自然而然达成的因果（反対が過半数に達した。従って法案は否決された）
それで因为…所以…（因果）
そこで在某种状况下…… → 后面一般跟有意志的行为（熊が近づいた。そこで死んだふりをした）※易与それで混用

顺接・补充・结果

表达用法
そして补充：后句补充前句 → 前后主语相同
すると于是…… → 前后主语一般不同（私が立つと、するとドアが開いた）
そうすれば／そうしなければ如果那样做／如果不那样做
その結果／結果として表示结果

总结

このように／以上のように／以上のことを踏まえて（基于以上论述）

逆接（转折）

表达语体
でも／だけど口语，书面语不用
しかし正式
しかしながら比しかし更正式
だが正式（论文可用）
それなのに与预想相反，带惊讶语气
それにもかかわらず同上，更正式
ところが与预想相反
どころか"别提…了"（强烈的主观反差）：褒めたつもりが、喜ぶどころか怒らせた

単纯逆接 vs 补充的逆接

表达用法
しかし単纯逆接（但是…）
ただし补充的逆接：不完全否定前文，只是补充条件（入場は自由。ただし6歳未満は保護者同伴）
もっとも同类（可能なら法律家になりたい。もっとも能力があればの話だが）

并列・累加

表达用法
および并列两个名词（居眠りおよびおしゃべりは禁止）
かつ更简洁更正式；还能连接两个小句（および一般不接小句）
それに累加（安くてそれにおいしい）；＋しても → 转折：それにしても（话虽如此）
しかも累加，强调后接的小句（美人でスタイルが良く、しかも料理上手）
おまけに累加，强调前面的句子，后句只是补充（暑い。おまけに風がない）
そればかりでなく／そればかりか不仅…而且

其他

功能表达
不管怎样ともかく／とにかく／いずれにしても；书面：いずれにしろ／いずれにせよ（せよ更书面）
与…相反逆に（口语）／反対に（书面）
或者または（電話またはメール）／あるいは／もしくは（更正式）
累加并列 vs 或者また（累加）／または（或者）
原因（至于为什么…）なぜなら（后句必须以表示原因的から结尾）：今は公表できない。なぜならまだ検討の段階だから。
同类：というのは〜から／なぜかというと〜から
换句话说 / 总结つまり（①换句话说 ②总之）／要するに（引出总结）／すなわち（更正式，但只表"换句话说"，一般不表总结）
转换话题ところで／さて（更正式）

比喻句式

  • 「人生は**〜のようなもの**だ」（人生说起来就像旅途一样的东西）。

指示词

  • 分现场指示与文脉指示——写作中使用的是文脉指示（こ／そ 在文章中的指代）。
