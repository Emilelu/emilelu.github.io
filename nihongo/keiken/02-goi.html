補充法：词形空缺由别的词填补　#3

（BV1EF9CBDE7y，03:03）

英语的经典例子

  • go → went：went 原本属于另一个动词（wend），中英语时代 go 自身的过去形衰退，went 填补了这个位置。
  • 这种"某词活用体系的一部分由另一词形补足"的现象，一般称为补充法（suppletion）。

日语的自他对应

自动词他动词关系
沈む（状态变化）沈める（有意引起该状态）有形态派生
焼ける（结果）焼く（意志行为）有形态派生
生まれる生む有形态派生

关键空缺：「死ぬ」没有对应的他动词

  • 死ぬ 在形态上没有直接对应的他动词。
  • 要表达"让某人死／致死"，必须用另一个词「殺す」。
  • 即：死ぬ 与 殺す 在意义上是自他对应关系，但在形态上没有派生关系 → 广义上也可视为一种补充法式对应。

类型学差异（这才是难点）

语言「死ぬ」「殺す」关系
韩语죽다 (chukda)죽이다 (chugida)后者由前者使役派生（形态对应）
日语 / 中文死ぬ / 死殺す / 杀不同词根，非规则派生

→ 这类语言类型的差异常在外语学习中制造困难：韩语母语者能靠形态推，日语/中文学习者不行。

水土不服的"词根记忆法"　#4

（BV1qNLw6rEbx，05:00）

为什么英语适合用"词根"记单词

  • 英语有大量拉丁语・希腊语来源的长词，且能较清晰地分解：
    • biology / psychology / transportation / international
  • 知道语根・接头辞・接尾辞，就能推测未知词的大致含义 → 词源学习法是高效整理长词的手段。

但日语不能照搬

日语词汇由和語・漢語・外来語构成（国立国語研究所 1956 年杂志调查，异なり語数）：

类别占比
漢語47.5%
和語36.7%
外来語9.8%
混種語6.0%

分类对策：

类别记法
漢語中国话者看汉字就能推义 → 重点在读音、用法、以及与中文的语义偏差，不是词根分析
外来語与其在日语内部拆词根，不如意识到它与来源英语的对应来记
和語单纯语本来就短（基本语多为 1–3 拍，6 拍已算长，如「くすぐったい」「あわただしい」）→ 没必要再细分拆解

补充：日语的表音优势

  • 假名能较规则地表记发音（「かな」是子音＋元音的まとまり）→ 比英语（拼写与发音对应复杂）易记。
  • 有些词看似单纯语，实为多个和语结合（如含「道」「引く」「帰る」「見る」等要素的词）——但词汇量上来后自然能辨认，不必特别记忆。

结论

英语的词源学习法在日语学习中不适用；按词类采取不同策略更高效。

拒绝"民科词源学"　#5

（BV1LjL463EBy，05:31）

典型伪词源：给假名硬安意义

  • 例如"「あ」表示明亮・热・向上・感动"这类说法。
  • 根本问题：混淆表音文字与表意文字。
    • 假名本来不是表示意义的记号。
    • 即便讨论的是音节/音素，只举几个语例就断定"某发音固定表示某意义"也不成立——任何发音都能靠强行搜集例证附会出意义。
  • 同类错误："「か」表示交换" → 实际与"交换"义相关的是含子音的语根形式「か＋子音」，不是孤立的一个音节「か」。

真正的词源学需要什么

综合考察：历史语形・音韵变化・语义变化・文献证据。

三个正面例子

  1. 注意语义的历史变化——「かわいい」
    • 来自古语「かわゆし」，原本表示"羞耻、看不下去"。
    • 接近现代义（可爱）的用法是后来才发展的，一般认为室町时代以后才明确。
    • → 不能从现代义逆推词源。
  2. 注意已消失/变形的古语形——「伝える」
    • 古形「つつ」→ 生「つとう」→ 室町时代出现「つたゆ」（下二段活用）。
    • 不追溯古形与活用变化，就会把后代产生的语形误当成最初就有的形。
  3. 需要古典语法知识——「たそがれ（黄昏）」
    • 来自「たそかれ」＝「あれは誰か」（那是谁？）。
    • 黄昏时光线变弱、看不清远处的人 → 于是这个表达转指傍晚时段。
    • 其中的「そ」是古语的係助词，与后世的「ぞ」有关（一般认为「ぞ」源自上代的「そ」）。
    • → 不懂古典助词与构文，就无法正确理解这个词的由来。

英语正字法 vs 历史假名遣　#6

（BV1UTVw6pEZF，04:56）

相似点一：拼写保存古音

  • 英语 night / right 的 gh：现代不发音，但历史上确实有音 → 拼写保存了旧发音。
  • 类似日本的历史假名遣（如「かはいい」写作古形，读音已变）。
  • 共同点：发音变了，表记仍保留旧貌。

相似点二：整体记读的"熟字训"

  • 日语熟字訓：词整体有特殊读法（今日／大人／明日）。
  • 英语也有无法逐字预测发音的词：one、colonel → 只能整体记住读音。

英语拼写改革为什么难

  1. 多国使用：英、美、加、澳、印、新…… 没有任何一国政府能统一表记。
  2. 地域发音差异大：如 car 的 r（美音多发、英音部分不发）、bath（美音 vs 英南部音）→ 按哪个地区的发音改？
  3. 拼写承载词源・词形信息：
    • sign 的 g 不发音，但 signal / signature 里发音 → 保留拼写能显示同语源关系；改成按发音书写，这层关系就看不见了。

日本的假名遣改革为什么能成功

条件日本英语
统一的推行主体政府・学校・出版社・新闻社遵循共同基准无
改革范围基本限于日本国内，可以标准语为基准跨国、无基准
改革性质只把假名部分按现代发音整理；汉字保留（承担语义区分与词的まとまり）若全按发音改，会丢掉词源信息

→ 日本废除历史假名遣，但并未把书写中的历史性与语义全部剥离：假名合现代音，汉字保意义。

「新聞」为什么是报纸：无处不在的转喻　（新投稿）

（BV12maP6BEiF，02:17）

起点：初学者都被提醒过的那件事

  • 日语里「新聞」＝报纸，不是中文的"新闻"。
  • 但「新聞」字面上是"新听到的事"，词本身没有任何指物理纸张的成分。
  • 其实我们是在无意识地使用转喻这种修辞法。

转喻（換喩・メトニミー）

表现某事物时，用与之有深度关联的另一词来替换的修辞法。

  • 转喻在日常中无处不在，是语言生活不可或缺的。

  • 讲义中把下面这种也算作转喻的延伸：

    技法说明例
    提喩（シネクドキ）上位概念 ↔ 下位概念、或部分 ↔ 整体互换「手が足りない」——用身体的一部分「手」表劳动者・劳动力
    同上「花」（上位：一切植物的花）→「花見」时特指樱花（下位）

  • 中文例子：「吃火锅」——吃的不是金属或土做的锅，而是里面的食材。

从历史语言学看

  • 这类修辞法使词义定着或变化的情况绝不罕见。
  • 因为太融入日常，许多词是在未被意识到是修辞法的状态下被使用的。

「新聞」的定着过程

  • 因多用于「読売新聞」等专有名词 → 明治 20 年代便专门定着为"报纸"之意。
  • 而「新聞紙」则让人意识到**"作为纸"的性质**（两者的分工由此形成）。
